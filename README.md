# Hyrox Training - Bordeaux

**🔗 Accéder au site : <a href="https://antoningd19.github.io/hyrox-training/" target="_blank" rel="noopener">antoningd19.github.io/hyrox-training</a>**

Site de suivi et préparation pour **l'Hyrox de Bordeaux** (3 octobre 2026, Parc des Expositions Bordeaux-Lac).

Deux prépas, accessibles via la bascule **Hyrox / Semi** en haut de page :

- `index.html` : prépa Hyrox Bordeaux (3 octobre 2026).
- `semi.html` : prépa du **semi-marathon de Bordeaux** (8 novembre 2026, objectif sous 1h35), avec plan sur 5 semaines, calculateur d'allure et plan gels.

Le dernier choix est mémorisé ; sans choix, la prépa semi s'ouvre par défaut depuis la fin de l'Hyrox.

Page HTML autonome (PWA installable), sans dépendance ni build, avec plan d'entraînement hebdomadaire et suivi de séances.

## Utilisation

Ouvrir le lien ci-dessus dans un navigateur, ou installer sur l'écran d'accueil (iPhone/Android) via "Ajouter à l'écran d'accueil" pour une utilisation en PWA.

Pour lancer en local : ouvrir `index.html` directement dans un navigateur.

## Stack

- HTML/CSS/JS vanilla, un fichier autonome par prépa
- Manifest PWA pour installation en application
